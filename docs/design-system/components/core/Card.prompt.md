`Card` is the surface primitive. No shadows — differentiate by ink step + hairline.

```jsx
<Card tone="accent">…the one clickable hook…</Card>
<Card tone="card">…secondary hook…</Card>
<Card tone="strong">…tertiary hook…</Card>
```

Tones: `raised` (chart wells), `card`, `strong`, `accent` (max one per row), `outline`. Default padding `24px 26px`; drop to `20px 20px` under 768px.
