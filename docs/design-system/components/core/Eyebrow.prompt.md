`Eyebrow` is the mono uppercase label above a section, stat or chart. Almost every block in this system opens with one.

```jsx
<Eyebrow tone="accent" dot>Your grid, right now</Eyebrow>
<Eyebrow>World generation mix · 100% stacked</Eyebrow>
```

Keep them under ~40 characters. Use `tone="accent"` at most once per screen.
